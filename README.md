📚 Tutor App — Mobile Learning PlatformA full-featured mobile application platform connecting students with qualified private tutors based on location, academic requirements, and subject specialization.📑 Table of ContentsOverviewKey FeaturesFor StudentsFor TutorsArchitecture & Tech StackProject StructureGetting StartedPrerequisitesInstallationFirebase SetupAPI ReferenceContributingLicense🧐 OverviewThe Tutor App bridges the gap between students seeking targeted academic assistance and qualified tutors looking to manage their teaching services. Using location-based matching and subject categorization, the application streamlines tutor discovery, booking, profile management, and session planning into an intuitive mobile workspace.✨ Key FeaturesFor StudentsGeolocation Tutor Search: Discover available tutors near your current location using Google Maps integration.Category & Subject Filtering: Filter verified tutors based on grade level, topic, or specific course requirements.Tutor Profiles: View detailed tutor credentials, subjects offered, rates, and current availability status.Session Requests: Connect directly with tutors to request tailored study sessions.For TutorsProfile & Bio Management: Create and update comprehensive tutor profiles detailing experience, pricing, and qualifications.Course Control: Add, edit, or remove subjects offered and set custom rates per session or topic.Availability Toggle: Easily switch tutor status between Available and Unavailable for instant visibility adjustments.Real-time Push Notifications: Receive instant updates regarding session booking requests via Firebase Cloud Messaging.🛠 Architecture & Tech StackClient Mobile AppLanguage: Java / KotlinUI Framework: Android XML Layouts, Material Design ComponentsNetworking: Android Fast Networking Library / RetrofitMaps & Geolocation: Google Maps SDK & Fused Location ProviderBackend & Cloud InfrastructureServer Framework: PHP RESTful API (Slim Framework)Database: MySQL Relational DatabaseAuthentication: Firebase AuthenticationPush Notifications: Firebase Cloud Messaging (FCM)📁 Project StructureTutor-App/

🚀 Getting StartedFollow these instructions to set up the project locally for development and testing.PrerequisitesEnsure you have the following installed on your development machine:Android Studio (Giraffe / Iguana or newer recommended)JDK 11 or JDK 17Android SDK (API Level 21+)A active Firebase Console projectInstallationClone the Repositorygit clone https://github.com/FABRICADO08/Tutor-App.git
cd Tutor-App
Open Project in Android StudioLaunch Android Studio.Click on Open an Existing Project.Select the cloned Tutor-App directory.Sync Gradle DependenciesLet Android Studio automatically download and resolve project dependencies.Firebase SetupGo to the Firebase Console and create a new project.Register an Android app using your package name (e.g., com.example.tutorapp).Download the generated google-services.json configuration file.Place google-services.json inside the Tutor-App/app/ directory:Tutor-App/
└── app/
    └── google-services.json
